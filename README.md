# Thesis Translation

Translate Chinese biology/biomedical thesis to English using Nature-Skills.

**Source thesis**: "探究人源ATG4介导的自噬在抗病毒免疫中的作用"
(Investigating the Role of Human ATG4-Mediated Autophagy in Antiviral Immunity)

**Author**: Ce Fang (方策)

## Structure

```
thesis_English.md    — Complete English translation
thesis_bilingual.md  — Paragraph-level Chinese/English side-by-side
sections/            — Individual translated chapters
assets/              — Extracted figures and tables
translation_notes.md — Terminology glossary and translation decisions
```

## Methodology

Translation powered by [nature-skills](https://github.com/Yuan1z0825/nature-skills) — specifically `nature-polishing` (zh-to-en mode) for academic translation into Nature-leaning English.
